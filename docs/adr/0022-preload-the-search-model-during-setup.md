# Preload the search model during setup

`brainhub-mcp setup` downloads and caches the pinned local semantic-search model by default. The setup UI displays the expected download size, live progress, and final cache location. The model is not bundled into the npm package and is not silently deferred until the first search, keeping the package smaller while making search readiness explicit during installation. Readiness requires a successful model load followed by an atomic completion marker tied to model, revision, and dimensions; partial cache bytes are not readiness. A download failure does not roll back or block Google authorization, uploads, portrait access, client registration, or scheduled tasks; semantic search is reported as unavailable with a retry action until the download succeeds.

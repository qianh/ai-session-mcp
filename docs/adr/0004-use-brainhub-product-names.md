# Use BrainHub product names consistently

The public product family is named BrainHub. The browser extension is BrainHub Capture, the local MCP is BrainHub MCP, its CLI command is `brainhub-mcp`, and the Drive data directory remains `brain-hub`. Repository names may remain unchanged to preserve existing Git URLs, but `AI Session`, `Brain Capture`, and `brain-mcp` are not public product names.

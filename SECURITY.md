# Security Policy

## Supported versions

Only the latest published BrainHub MCP version receives security fixes. Version 1 supports macOS and Linux.

## Reporting a vulnerability

Use the repository's private GitHub Security Advisory form. Do not open a public issue for OAuth credentials, token exposure, Drive authorization bypasses, path escapes, or sensitive-session disclosure.

Never attach refresh tokens, OAuth client secrets, raw CLI sessions, Keychain or Secret Service exports, or private Drive file IDs. Include a minimal reproduction with redacted data and the affected version.
